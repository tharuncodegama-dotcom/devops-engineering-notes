## 3. PostgreSQL 16 Container Setup

### Objective
Deploy PostgreSQL inside Docker, configure persistent storage, connect using `psql`, and practise basic SQL operations.

### Work Completed

- Created a Docker named volume for PostgreSQL data.
- Started a PostgreSQL 16 container named `postgres-lab`.
- Configured the initial database as `devops_lab`.
- Configured the database user as `devops_user`.
- Mounted the named volume at `/var/lib/postgresql/data`.
- Checked the container status and reviewed its startup logs.
- Confirmed that PostgreSQL initialized successfully and became ready to accept connections.
- Connected to PostgreSQL from inside the container using `docker exec`.
- Created an `employees` table and inserted three sample records.

### Container Configuration

| Item | Value |
|---|---|
| Container | `postgres-lab` |
| Image | `postgres:16` |
| Database | `devops_lab` |
| Database user | `devops_user` |
| Named volume | `postgres_lab_data` |
| Data mount | `/var/lib/postgresql/data` |
| PostgreSQL port | 5432 inside the container |

PostgreSQL was not published to the EC2 host using `-p`, so the lab used an internal container connection.

### Commands Used

Create persistent storage:

```bash
sudo docker volume create postgres_lab_data
sudo docker volume ls
```

Start PostgreSQL:

```bash
sudo docker run -d \
  --name postgres-lab \
  -e POSTGRES_USER=devops_user \
  -e POSTGRES_PASSWORD='Choose_A_Strong_Practice_Password' \
  -e POSTGRES_DB=devops_lab \
  -v postgres_lab_data:/var/lib/postgresql/data \
  postgres:16
```

Inspect the container and logs:

```bash
sudo docker ps
sudo docker logs postgres-lab
```

Connect to PostgreSQL:

```bash
sudo docker exec -it postgres-lab \
  psql -U devops_user -d devops_lab
```

Verify the database and user:

```sql
SELECT current_database(), current_user;
```

Inspect tables:

```sql
\dt
```

Inspect the table structure:

```sql
\d employees
```

### Table Created

```sql
CREATE TABLE employees (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    role VARCHAR(100),
    salary NUMERIC(10,2)
);
```

### Sample Data Inserted

```sql
INSERT INTO employees (name, role, salary)
VALUES
    ('Arun', 'DevOps Engineer', 50000.00),
    ('Priya', 'System Administrator', 40000.00),
    ('Rahul', 'Cloud Engineer', 55000.00);
```

### Verification Results

- PostgreSQL container was running.
- Startup logs confirmed that PostgreSQL was ready to accept connections.
- Successfully connected to the `devops_lab` database.
- Created the `employees` table.
- Inserted three employee records and retrieved them using `SELECT * FROM employees`.

### Key Learnings

- Docker containers can run database services independently of applications installed directly on the EC2 host.
- Named volumes store database files outside the container's writable layer and help preserve data when a container is replaced.
- `docker exec -it` allows interactive commands inside a running container.
- `psql` is PostgreSQL's interactive command-line client.
- `SERIAL PRIMARY KEY` generates integer IDs and identifies each record uniquely.
- SQL commands such as `CREATE TABLE`, `INSERT`, and `SELECT` are fundamental database operations.
