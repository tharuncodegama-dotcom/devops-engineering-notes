## 5. Dockerfile Review — Java Market Data History Service

### Work completed
- Reviewed a multi-stage Dockerfile for the `bhimmarkets-market-data-history` Java service.
- Examined the three main stages:
  1. Build and install the observability SDK using Maven.
  2. Build the application JAR using Maven and Java 21.
  3. Create a smaller runtime image using the Java 21 JRE Alpine image.
- Reviewed the non-root runtime user, exposed port `8820`, container health check, and Java runtime options.

### Important build requirements
The Docker build context must contain the following directories:

```text
project-root/
├── Dockerfile
├── observability-sdk/
│   ├── pom.xml
│   └── src/
└── market-data-history/
    ├── pom.xml
    └── src/
```

The build must run from the project root, or specify that directory as the build context.

### Example build command
```bash
sudo docker build \
  -t bhimmarkets-market-data-history:latest \
  -f Dockerfile .
```

### Key learning
- Understood multi-stage Docker builds, build contexts, Dockerfile selection using `-f`, Maven compilation, runtime images, health checks, and image inspection.
- Learned that successful image creation and successful application startup are separate verification steps.
