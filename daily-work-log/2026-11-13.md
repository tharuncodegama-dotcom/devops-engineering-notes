## 12. Key DevOps Learnings

1. Application migration requires more than copying source code.
2. Runtime versions and dependencies must match application requirements.
3. Laravel deployments require correct Composer dependencies, environment configuration, permissions, and database connectivity.
4. Node.js services need proper port planning and process management.
5. Frontend applications require production builds before Apache hosting.
6. Apache virtual hosts allow multiple applications to use separate domains on one server.
7. Reverse proxy configuration connects public domains to internal Node.js services.
8. DNS must resolve correctly before SSL certificate issuance.
9. HTTPS configuration should be verified after certificate installation.
10. tmux and PM2 help manage long-running application processes.
