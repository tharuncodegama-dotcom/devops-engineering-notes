### 3.4 Security Group Configuration

Practiced designing security group rules according to application-tier requirements.

The intended communication flow is:

- Internet → Frontend: HTTP/HTTPS.
- Frontend → Backend: TCP port `3000`.
- Backend → Database: TCP port `3306`.
- SSH access: restricted to the intended administrative source for the lab.

The backend API and database ports should not be directly exposed to the public internet.

The NAT Gateway provides outbound internet access for private instances when their route tables direct traffic through it. It is not required for communication between the three instances using their private IP addresses.
