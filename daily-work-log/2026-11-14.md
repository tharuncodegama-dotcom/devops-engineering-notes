## 11. Laravel Application Containerization

Worked on the `laravel-postgres-app` project.

Built a custom PHP image containing the Laravel application and PostgreSQL PHP driver.

**Dockerfile:**

```dockerfile
FROM php:8.3-cli

RUN apt-get update && apt-get install -y \
    git \
    unzip \
    libpq-dev \
    && docker-php-ext-install pdo_pgsql \
    && apt-get clean \
    && rm -rf /var/lib/apt/lists/*

COPY --from=composer:2 /usr/bin/composer /usr/bin/composer

WORKDIR /var/www/html

COPY . .

RUN composer install --no-interaction --prefer-dist \
    && chown -R www-data:www-data storage bootstrap/cache

EXPOSE 8000

CMD ["php", "artisan", "serve", "--host=0.0.0.0", "--port=8000"]
```

Created a `.dockerignore` file to exclude unnecessary files and sensitive configuration:

```text
.git
.env
.env.*
vendor
node_modules
Dockerfile
.dockerignore
```

Built the image:

```bash
sudo docker build -t laravel-postgres-app:1.0 .
```

Image size was approximately 967 MB.

Started the Laravel container:

```bash
sudo docker run -d \
  --name laravel-app \
  --network postgres-network \
  -p 127.0.0.1:8000:8000 \
  --env-file .env \
  laravel-postgres-app:1.0
```

Configured the Laravel application to connect to PostgreSQL using the database container name as its hostname.

## 16. Key DevOps Learnings

1. Docker images are templates used to create containers.
2. Containers provide isolated application runtime environments.
3. Dockerfiles define how custom application images are built.
4. Container ports and host ports are different.
5. Named volumes preserve important application data independently of container lifecycle.
6. Docker bridge networks enable communication between application containers.
7. Container names can be used for service discovery on user-defined networks.
8. Database backup and restore are essential operational skills.
9. Docker logs, events, inspect, and journal logs help investigate container failures.
10. Applications can be containerized independently and connected as multi-container systems.
11. Environment variables should be used to configure application containers.
12. Laravel applications need their dependencies, PHP extensions, environment configuration, and database connectivity to work correctly.
13. Database-backed Laravel sessions require a valid sessions table.
14. Application verification should include both HTTP responses and database connectivity.
