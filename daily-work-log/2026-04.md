### 5. Commands Used

**Check Apache HTTPS listener:**

```bash
sudo ss -lntp | grep ':443'
```

**Request SSL certificate:**

```bash
sudo certbot --apache \
  -d herald-otc-admin-dev.heraldex.com \
  -d herald-otc-api-dev.heraldex.com \
  -d herald-otc-dev.heraldex.com
```

**Check installed certificates:**

```bash
sudo certbot certificates
```

**Check Apache configuration:**

```bash
sudo apache2ctl configtest
```
