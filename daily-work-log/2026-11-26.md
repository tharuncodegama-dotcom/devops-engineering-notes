## 2. Commands Used

**Inspect virtual-host configurations:**
```bash
sudo cat /etc/apache2/sites-available/<config-file>
```

**List matching configuration files:**
```bash
ls -l /etc/apache2/sites-available/*<domain-pattern>*
```

**Audit IP restriction directives:**
```bash
sudo grep -RniH "Require ip" /etc/apache2/sites-available/
```

**Find virtual-host files without an IP restriction:**
```bash
for f in /etc/apache2/sites-available/*.conf; do
  if grep -q "<VirtualHost" "$f" && ! grep -q "Require ip" "$f"; then
    echo "MISSING: $f"
  fi
done
```

**Check active Apache virtual hosts:**
```bash
sudo apache2ctl -S
```

**Check whether a configuration is enabled:**
```bash
ls -l /etc/apache2/sites-enabled/
```

**Validate Apache configuration:**
```bash
sudo apache2ctl configtest
```

**Reload Apache:**
```bash
sudo systemctl reload apache2
```

**Test application responses:**
```bash
curl -I https://<domain>
```
