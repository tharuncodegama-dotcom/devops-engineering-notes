## 3. New Topic Learned: tmux

### A. Introduction

Learned about `tmux`, a terminal multiplexer that allows multiple terminal sessions to run within one terminal window.

### B. Why tmux Is Useful in DevOps

- Keeps a terminal session running when an SSH connection disconnects, provided the tmux server remains running.
- Supports long-running commands and monitoring tasks.
- Allows multiple terminal windows and split panes.
- Makes remote server administration more convenient.

### C. Important Commands

```bash
# Install tmux
sudo apt update
sudo apt install tmux -y

# Start a new session
tmux

# Create a named session
tmux new -s devops

# List sessions
tmux ls

# Detach from the current session
# Press Ctrl+B, then D

# Reattach to a session
tmux attach -t devops

# Reattach to the most recent session
tmux attach

# Kill a named session
tmux kill-session -t devops
```

### D. Important tmux Shortcuts

| Shortcut | Purpose |
|---|---|
| `Ctrl+B`, then `D` | Detach from a session |
| `Ctrl+B`, then `C` | Create a new window |
| `Ctrl+B`, then `N` | Move to the next window |
| `Ctrl+B`, then `P` | Move to the previous window |
| `Ctrl+B`, then `%` | Split pane vertically |
| `Ctrl+B`, then `"` | Split pane horizontally |
| `Ctrl+B`, then arrow key | Move between panes |

**Key learning:** Detaching from tmux does not terminate the session. Commands running inside it can continue while the session remains alive, even after the SSH connection is disconnected.
